# 3D Tetris

ブラウザで動く3DテトリスHTML。Three.js (CDN) を使った単一ファイル実装。

## 遊び方

`index.html` をブラウザで開くだけ。ローカルサーバー経由でも動作します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。

## 操作

- 矢印キー: X/Z移動
- W / S : X軸回転
- A / D : Z軸回転
- Q / E : Y軸回転
- Space : ハードドロップ
- Shift : ソフトドロップ
- マウスドラッグ: 視点回転
- ホイール: ズーム

## ルール

5×5×12の井戸に3Dテトロミノが上から落ちてくる。1つのY層（5×5マス）が全部埋まると消える。レベルが上がると落下速度が上がる。
